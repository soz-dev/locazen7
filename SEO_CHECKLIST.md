# ✅ Checklist SEO - Actions à Faire

## 🚨 URGENT - À faire AUJOURD'HUI

### ☐ 1. Google Search Console
**Pourquoi ?** Sans cela, Google ne sait pas que votre site existe !

**Comment faire ?**
1. Allez sur https://search.google.com/search-console
2. Cliquez sur "Ajouter une propriété"
3. Entrez : `https://www.locazen7.fr`
4. Choisissez une méthode de vérification :
   - **Option A (Recommandée)** : Balise HTML (déjà dans votre code)
   - **Option B** : Fichier HTML (remplacez `/public/google-site-verification.html`)
5. Une fois vérifié, allez dans "Sitemaps"
6. Ajoutez : `https://www.locazen7.fr/sitemap.xml`

**Temps estimé** : 10 minutes

### ☐ 2. Vérifier l'indexation actuelle
**Dans Google, tapez :**
```
site:locazen7.fr
```

**Si aucun résultat** :
- Votre site n'est PAS indexé
- Passez à l'étape 1 immédiatement !

**Si des résultats apparaissent** :
- Notez combien de pages sont indexées
- Vérifiez que ce sont les bonnes pages

**Temps estimé** : 2 minutes

## ❓ Questions Fréquentes

### Combien de temps pour voir des résultats ?
- **2-4 semaines** : Indexation
- **1-3 mois** : Premiers clics
- **3-6 mois** : Positionnement correct
- **6-12 mois** : Bons résultats

### Pourquoi je ne vois pas mon site sur Google ?
Causes principales :
1. Site pas indexé → Google Search Console
2. Site trop récent → Patience + backlinks
3. Concurrence forte → Contenu + backlinks
4. Problème technique → Vérifier robots.txt

### Faut-il payer pour être référencé ?
**Non !** Le référencement naturel est gratuit.
Vous pouvez payer pour :
- Google Ads (publicités, résultats immédiats)
- Prestataire SEO (si vous manquez de temps)

### Mon site est lent, est-ce grave ?
Oui ! La vitesse est un critère de référencement.
Testez sur : https://pagespeed.web.dev
